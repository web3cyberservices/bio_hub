# PRO Себя — Ваш персональный ИИ нутрициолог

**PRO Себя** — это передовая ИИ-платформа (BioTech Intelligence), разработанная для управления здоровьем, питанием и образом жизни на основе биометрических данных пользователя.

## Основные возможности

- **Умный анализ еды**: Распознавание состава блюд и расчет КБЖУ по фото или текстовому описанию с использованием Google Gemini.
- **Персонализированные рекомендации**: Ежедневные отчеты по диете, образу жизни и приему добавок на основе ваших целей.
- **Интеграция с гаджетами**: Синхронизация шагов, пульса и сна из Apple Health, Google Fit и других устройств.
- **Клинический интеллект**: Учет результатов анализов и хронических состояний при формировании меню.
- **Премиальный UI**: Футуристичный дизайн "BioTech Platinum" с упором на удобство мобильных пользователей.

## Технологический стек

- **Framework**: Next.js 15 (App Router)
- **AI Engine**: Firebase Genkit + Gemini 2.5 Flash
- **Styling**: Tailwind CSS + ShadCN UI
- **Components**: Radix UI, Lucide Icons
- **Analytics**: Recharts (инфографика макронутриентов)

## Как запустить локально

1. Установите зависимости:
   ```bash
   npm install
   ```
2. Настройте переменные окружения:
   Создайте файл `.env` и добавьте туда `GEMINI_API_KEY`.
3. Запустите сервер разработки:
   ```bash
   npm run dev
   ```
4. Откройте [http://localhost:9002](http://localhost:9002).
