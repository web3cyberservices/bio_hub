# PRO Себя — Ваш персональный ИИ био-хаб (BioTech Intelligence)

**PRO Себя** — это ультимативная BioTech-платформа, разработанная для глубокого управления здоровьем, питанием и образом жизни. Система объединяет возможности носимых устройств, лабораторной диагностики и мультимодального ИИ Google Gemini для создания единой экосистемы долголетия.

## 🚀 Технологический стек

- **Frontend**: Next.js 15 (App Router) / React 19
- **AI Core**: Firebase Genkit + Gemini 2.5 Flash
- **Backend/Database**: Google Cloud Firestore (Real-time sync)
- **Auth**: Firebase Authentication (Google, Email, Anonymous)
- **UI System**: Tailwind CSS + ShadCN UI (Custom "Bio-Tech Platinum" Theme)
- **Voice Engine**: Web Speech API (Интеграция во все формы ввода)
- **Data Viz**: Recharts (Интерактивная биометрическая инфографика)

## ✨ Полный функционал приложения

### 1. Интеллектуальный Дашборд (Bio-Hub)
- **Bio-Score 4.0**: Визуальный индикатор состояния здоровья (0-100), рассчитываемый ИИ на основе баланса макронутриентов, активности и сна.
- **Трекинг макросов**: Интерактивные кольца прогресса для Белков, Жиров и Углеводов с учетом индивидуальных целей.
- **Fasting Timer**: Умный таймер интервального голодания (16:8 и др.) с расчетом времени до следующего приема пищи.

### 2. Умная система питания
- **Neuro-Scanner**: Мгновенный анализ КБЖУ блюда по одной фотографии или текстовому описанию.
- **AI Auto-calculation**: Автоматическое заполнение нутриентов при добавлении блюда вручную (система "введи название — ИИ сделает остальное").
- **Smart Inventory**: Генерация меню из имеющихся продуктов. Поддерживает анализ фото содержимого холодильника.
- **Замена блюд**: Возможность в один клик попросить ИИ предложить альтернативу блюду из плана, если оно вам не нравится или недоступно.

### 3. Лабораторная диагностика (LabScan AI)
- **Анализ отчетов**: Автоматическое распознавание биомаркеров (Ферритин, Витамин D, Холестерин и др.) с фотографий медицинских бланков.
- **Интерпретация**: Пояснение значений простым языком и оценка их статуса относительно референсных интервалов.
- **AI Рекомендации**: Практические советы по коррекции рациона или образа жизни на основе найденных отклонений.

### 4. Сообщество и экспертная поддержка
- **Bio-Лента**: Единый поток знаний, где сертифицированные специалисты делятся статьями, а ИИ-консилиум дает краткие выжимки.
- **Профили специалистов**: Просмотр квалификации, специализации, рейтинга и отзывов реальных пациентов.
- **Система чатов**: Полноценный мессенджер для связи с врачами и нутрициологами с поддержкой редактирования и удаления сообщений.

### 5. Персонализация и биометрия
- **Глубокий профиль**: Учет веса, роста, возраста, целей (похудение/баланс/набор), вредных привычек и пищевых аллергий.
- **Smart Sync**: Синхронизация шагов, пульса и сна из носимых устройств (симуляция Health Kit).
- **Дневник самочувствия**: Отслеживание настроения и уровня энергии.

### 6. Доступность и UX
- **Voice Interface**: Иконка микрофона в каждом поле ввода позволяет диктовать данные голосом.
- **Barcode Scanner**: Быстрое добавление продуктов через сканирование штрих-кодов упаковки.
- **Guest Mode**: Возможность протестировать весь функционал без регистрации в один клик.

## 🛠 Установка и развертывание

1. **Зависимости**:
   ```bash
   npm install
   ```
2. **Конфигурация**:
   - Создайте файл `.env` и добавьте `GEMINI_API_KEY`.
   - Настройте Firebase через консоль и обновите `src/firebase/config.ts`.
3. **Запуск**:
   ```bash
   npm run dev
   ```
