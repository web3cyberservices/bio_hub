# PRO Себя — Ваш персональный ИИ био-хаб (BioTech Intelligence)

**PRO Себя** — это передовая BioTech-платформа, разработанная для управления здоровьем, питанием и образом жизни на основе биометрических данных пользователя и мощностей искусственного интеллекта Google Gemini.

## 🚀 Технологический стек

- **Framework**: Next.js 15 (App Router) / React 19
- **AI Engine**: Firebase Genkit + Gemini 1.5 Flash (Мультимодальный анализ)
- **Backend/DB**: Google Cloud Firestore
- **Auth**: Firebase Authentication (Google, Email, Anonymous)
- **Styling**: Tailwind CSS + ShadCN UI (Custom "Bio-Tech Platinum" Theme)
- **Data Viz**: Recharts (Интерактивная инфографика)
- **Validation**: Zod (Строгая типизация схем ИИ)

## ✨ Основные возможности

- **Bio-Score 4.0**: Единый индекс здоровья, рассчитываемый ИИ на основе ваших показателей за день (сон, шаги, питание, энергия).
- **Нейро-сканирование еды**: Распознавание состава блюд по фото с детальной разбивкой на ингредиенты (FatSecret/YAZIO Style).
- **Интеграция с профилем**: Автоматическое использование веса, роста и целей для персонализации всех расчетов.
- **Дневник самочувствия**: Отслеживание настроения и уровня энергии (Flo Style).
- **Смарт-трекинг**: Мониторинг шагов, сна, пульса и водного баланса в едином футуристичном интерфейсе.
- **Expert AI Chat**: Круглосуточный доступ к знаниям в области нутрициологии и биохакинга.

## 🛠 Установка и запуск

1. **Зависимости**:
   ```bash
   npm install
   ```
2. **Конфигурация**:
   - Создайте `.env` и добавьте `GEMINI_API_KEY`.
   - Настройте `src/firebase/config.ts` через кнопку "Connect to Firebase" в Studio.
3. **Разработка**:
   ```bash
   npm run dev
   ```
