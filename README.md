# PRO Себя — Ваш персональный ИИ био-хаб (BioTech Intelligence)

**PRO Себя** — это ультимативная BioTech-платформа, разработанная для глубокого управления здоровьем, питанием и образом жизни. Система объединяет возможности носимых устройств, лабораторной диагностики и мультимодального ИИ Google Gemini для создания единой экосистемы долголетия.

## 🚀 Технологический стек

- **Frontend**: Next.js 15 (App Router) / React 19 / TypeScript
- **AI Core**: Firebase Genkit + Gemini 2.5 Flash (мультимодальный анализ данных)
- **Backend/Database**: Google Cloud Firestore (Real-time sync)
- **Auth**: Firebase Authentication (Google, Email, Anonymous / Guest Mode)
- **UI System**: Tailwind CSS + ShadCN UI (Кастомная тема "Bio-Tech Platinum")
- **Voice Engine**: Web Speech API (Интеграция голосового ввода во все формы)
- **Integrations**: Google Fit API (Биометрия), docx (Генерация отчетов)

## ✨ Полный функционал приложения

### 1. Интеллектуальный Дашборд (Bio-Hub)
- **Bio-Score 4.0**: Единый индекс здоровья, рассчитываемый ИИ на основе активности, питания и показателей сна.
- **Трекинг макросов**: Интерактивные кольца прогресса для Белков, Жиров и Углеводов.
- **Fasting Timer**: Умный таймер интервального голодания с расчетом времени до следующего приема пищи.

### 2. Лабораторная диагностика (LabScan AI)
- **Анализ отчетов**: Автоматическое распознавание биомаркеров с фотографий медицинских бланков.
- **Интеллектуальные нормы**: ИИ рассчитывает персональные референсные значения на основе пола и возраста, даже если они не указаны в бланке.
- **Экспорт в DOCX**: Генерация полноценного медицинского отчета с расшифровкой ИИ для печати или отправки врачу.

### 3. Умная система питания (MealScan AI)
- **Neuro-Scanner**: Мгновенный анализ КБЖУ блюда по одной фотографии или текстовому описанию.
- **AI Auto-calculation**: Автоматическое заполнение нутриентов при добавлении блюда вручную.
- **Smart Inventory**: Генерация меню из имеющихся продуктов или по фото холодильника.
- **Замена блюд**: Возможность в один клик попросить ИИ предложить альтернативу блюду из плана.

### 4. Взаимодействие со специалистами
- **Профили экспертов**: Просмотр специализации, рейтинга и социальных сетей (Instagram) врачей и нутрициологов.
- **Data Sharing**: Безопасная передача своих биометрических данных и анализов специалисту для удаленной консультации.
- **Система чатов**: Реально-временной мессенджер с поддержкой голосового ввода и управления сообщениями.

### 5. Персонализация и доступность
- **Smart Sync**: Прямая синхронизация шагов, пульса и сна из Google Fit.
- **Voice Interface**: Возможность диктовать данные (вес, состав еды, симптомы) голосом.
- **Barcode Scanner**: Быстрое добавление продуктов через сканирование штрих-кодов упаковки.
- **Guest Mode**: Тестирование всего функционала без регистрации в один клик.

## 🛠 Установка и развертывание

1. **Зависимости**:
   ```bash
   npm install
   ```
2. **Конфигурация**:
   - Создайте файл `.env` и добавьте `GEMINI_API_KEY`.
   - Настройте Firebase через консоль и обновите `src/firebase/config.ts`.
3. **Запуск**:
   ```bash
   npm run dev
   ```
