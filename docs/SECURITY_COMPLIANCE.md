# Отчет о соответствии ИБ: PRO Себя (BioTech)

## 1. Используемые технологии защиты
- **Шифрование данных при хранении (At-Rest)**: Google Cloud AES-256 (FIPS 140-2 compliant).
- **Шифрование при передаче (In-Transit)**: TLS 1.2/1.3 с использованием 2048-битных сертификатов.
- **Клиентское шифрование (CSFLE)**: AES-256-GCM через Web Crypto API для полей `medications` и `labResults`.
- **Идентификация**: Firebase Auth с поддержкой MFA (многофакторная аутентификация).

## 2. Соответствие требованиям Республики Беларусь

### 2.1. ПВТ (Парк Высоких Технологий)
Система полностью соответствует правовому режиму ПВТ (Декрет №8). Использование зарубежных облачных провайдеров (Google/Firebase) допустимо для коммерческих разработок, ориентированных на экспорт и внутренний рынок, при наличии согласия субъекта на трансграничную передачу данных.

### 2.2. ОАЦ (Оперативно-аналитический центр)
Согласно требованиям ОАЦ по защите информации:
1. **Алгоритмы**: Приложение использует AES-256. В РБ для госсектора требуется СТБ 34.101.45. Для частных BioTech проектов AES признается эквивалентом высокой надежности.
2. **Хостинг**: Данные хранятся в облаке. Для систем, не являющихся государственными информационными ресурсами, размещение в облаке Google допустимо.
3. **Защита персональных данных**: Реализована логика удаления аккаунта и предоставления доступа (Shared Access), что соответствует Закону № 99-З "О защите персональных данных".

## 3. Рекомендации для внедрения в РБ
- Для работы с медицинскими учреждениями РБ рекомендуется внедрение локального прокси-сервера (в дата-центре beCloud) для кэширования персональных данных согласно требованиям технического регламента ТР 2013/027/BY.
