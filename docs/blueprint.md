# **App Name**: NutriPath AI

## Core Features:

- User Authentication & Profile: Allow users to register and log in securely. Users can create and manage their personal profiles, storing basic information like name, email, and preferences, and also choose between a regular user or specialist profile.
- Health Data Input: Provide a structured form for users to input essential health data, including current weight, height, age, activity level (dropdown choices like малоактивный, среднеактивный, средний, активный, перенагрузка), and specific health goals (снизить массу тела, поддержать текущее состояние, или набор массы).
- Dietary & Labs Data Input: Offer an optional section for users to provide free-form text input regarding their daily food intake or results from recent lab analyses.
- AI Nutrition Tool: Leverage generative AI to process all provided user data (profile, health metrics, activity, goals, and optional dietary/lab inputs) to generate personalized, context-aware recommendations for lifestyle adjustments, diet plans, and suitable vitamin/supplement intake to improve health. The LLM will use reasoning to decide when or if to incorporate user-provided food lists or lab results as tools in its output.
- Personalized Recommendations Display: Present the AI-generated health recommendations clearly and systematically. Categorize advice for easy understanding, such as sections for lifestyle, food choices, and specific supplement suggestions.

## Style Guidelines:

- Primary color: A vibrant, healthy green (#4CAF50). This hue conveys freshness, nature, and well-being, associating the app with natural health.
- Secondary color: A warm, inviting orange (#FF9800). Used for highlights and interactive elements, this color signifies energy and accessibility, providing a friendly contrast.
- Accent colors: A cheerful yellow (#FFEB3B) for subtle accents and a deep, healthy red (#F44336) for attention-grabbing elements or warnings, ensuring a lively and engaging warm palette.
- Headline font: 'Space Grotesk' (sans-serif) for its modern, slightly techy, and direct feel, suitable for drawing attention to key sections and titles. Body font: 'Inter' (sans-serif) for exceptional readability across various screen sizes and text densities, ensuring that health recommendations are clear and easy to digest.
- Utilize a consistent set of minimalist, line-art icons. Icons should clearly represent health concepts, food items, activity levels, and data inputs, maintaining a clean and professional aesthetic aligned with the app's scientific approach.
- Adopt a clean, intuitive, and responsive layout with generous use of whitespace. Key information should be presented logically in distinct sections, especially for user input forms and recommendation displays, facilitating easy navigation and comprehension on all devices.
- Incorporate subtle, tasteful animations for transitions between sections, feedback upon data submission, and the loading of AI-generated content. These animations should provide positive user experience cues without being distracting.
